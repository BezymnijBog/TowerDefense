## Overview
Tower Defense started as a traditional tower defense prototype, but gradually evolved into a hybrid between Tower Defense and RTS. Instead of placing static defensive structures, the player recruits and positions military units directly on the battlefield to intercept enemy forces before they reach the castle.

## Goals

This project serves two purposes:
1. Explore gameplay programming in Unreal Engine 5.
1. Experiment with scalable gameplay architecture and modern C++ practices.

## Technical Highlights

The project emphasizes clean gameplay architecture over rapid prototyping.

Current technical goals include:
- Gameplay Ability System as the foundation for unit interactions
- Data-driven gameplay
- Modular gameplay systems
- C++-first implementation
- Separation between gameplay logic and presentation

## Current Features

- Melee and ranged units
- Navigation and movement
- Combat system
- Gameplay Ability System integration
- Health and damage system
- Unit recruitment UI
- Resource economy

## Roadmap

Near-term:
- Enemy wave management
- AI improvements

Future:
- Siege units
- Data-driven balancing
- Save/Load
- VFX
- Additional unit archetypes

## Development Philosophy

This project is developed incrementally.

Rather than designing the entire game upfront, I focus on implementing one gameplay system at a time, refining its architecture before moving on to the next feature.

This allows me to continuously improve both the gameplay and the underlying codebase.
